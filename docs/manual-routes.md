# 路线管理与独立配置链接

## 绘制路线

客户前台与管理后台都有独立「路线管理」入口。客户仅能访问自己账号的路线，包括通过自己任务的配置链接保存的路线；后台可查看全部用户，并按用户、账号、来源筛选。权限在后端校验，直接传入别人的路线 ID 也不会获得访问权限。

页面采用可搜索的路线列表、折线缩略图和地图预览；绘制弹窗分为资源选择与地图画布。来源标记区分「手动绘制」和「配置链接」，列表分页并限制高度，移动端改为单列。

1. 在「路线管理」选择「绘制路线」，依次选择账号、同步后的跑步计划与区域。
2. 地图自动定位区域，并显示边界。点击地图连接折点，拖动节点调整；工具栏支持撤销、反转和清空，右键节点可删除。
3. 路线长度必须**大于**计划最低距离。开放路线和闭合路线都支持，不自动补全或强制闭环。
4. 保存后在自动任务的「路线模式」选择「自定义路线」。列表只显示与账号、计划、区域匹配的路线。

服务端按 GCJ-02 坐标计算距离，忽略客户端提交的长度。对顶点及每段路线采样检查区域边界。单路线最多 10000 个点、100 km；绘制界面最多 2000 个节点，每账号最多保存 100 条路线。

任务距离仍使用计划允许的 100 m 档位，按次数统计的计划仍使用最低合格距离。任务距离大于手绘长度时拒绝保存；执行前再次校验。运行时保留原折线，从起点截取指定距离，只对终点插值，不重复或延长路线。如果截取段未经过起跑后返回的必经打卡点，本次执行失败并提示调整，不会改为自动路线。

已绑定任务的路线不允许删除；修改几何后必须仍容纳引用它的任务距离。修改路线不影响已开始运行的任务快照。

新建任务时读取最新地图配置：未配置地图 API Key 时仅支持自定义路线，添加账号时的自动创建任务选项也会停用。后台、客户下单与独立配置页共用后端校验；修改浏览器请求不会跳过限制。已有自动路线任务在移除 Key 后仍可暂停，再次启用前需配置 Key 或切换自定义路线。地图底图与手工绘制不依赖路径规划 Key。

## 帮他人下单

在「自动任务」列表点击链接按钮，生成独立配置链接，交给实际使用者。页面支持：

- 更新对应账号的自定义人脸照片；上传时移除图片元数据并加密保存。
- 选择自动路线、已保存路线或绘制新路线。
- 修改单次距离、执行时刻、允许的执行日、日/周次数及公里数限额。

配速、步频等仍由计划规则处理。链接不提供登录凭据、钱包余额、充值、购买、账号/计划/区域切换、立即运行或任务启停操作。

### 已付费范围

客户任务支持三种已付费范围：**按次预扣、按公里预扣、完整计划套餐**。客户新建任务时选择下单次数或公里数，核对金额后一次性确认，任务创建与余额预扣在同一事务内完成；余额不足或任务校验失败时，两者都不生效。余额本身不等于已付费额度；管理员和链接持有者不能代扣客户余额。管理员个人任务按生成链接时的任务范围授权，不产生费用。

### 调整下单总量

在任务编辑、配置链接弹窗或「余额与计费 → 任务计费 → 查看 / 调整额度」中修改**下单总量（包含已成功与执行中的量）**，账号和跑步计划不变。先预览服务端核算的金额，再确认调整。

| 部分 | 执行与退款规则 |
| --- | --- |
| 未执行 · 可退 | 增加总量按当前单价补预扣；减少总量退回相应的原预扣本金到余额 |
| 执行中 · 锁定 | 执行前预留 1 次或所选目标米数，同时锁定对应金额，暂不允许退回 |
| 已成功 · 已结算 | 从预扣本金结算，不再次扣可用余额；已结算数量和金额不支持退回 |

- 总量下限为「已成功 + 执行中」，点击「退回全部未执行额度」可将总量降至这个下限。即使后来停用新计费或购买完整套餐，原未执行本金仍可退回。
- 提交失败将原预留数量及金额返还任务可用额度，不自动退钱包；用户随后可减少总量退款。上游提交成功但本地记录保存失败时仍结算。进程异常或结果未确认时保持锁定，先核对结果，不自动退款。
- 不同单价的追加预扣合并为未执行资金池；减少或预留按该池「本金 × 本次数量 ÷ 可用数量」分摊，使用整数微 USDT 向下取整，最后一份取走余数。退款不使用新单价重算，累计退款与结算总额不超过原预扣本金。
- 下单 / 调整使用唯一请求号幂等处理；确认调整还校验报价版本和金额，额度或价格变化后须重新预览。退款、余额变动、订单和流水原子提交；结算幂等，重复成功回调或后续失败回调不重复扣费、不退已结算资金。
- 额度不足时不执行，**不自动改扣余额**。开启商业计费后，没有预付记录的旧客户任务也需先下单补充额度；不再沿用执行时直接扣余额的方式。
- 次数按整数，公里以整数米存储、按 100 m 增减；金额以整数微 USDT 存储。一次新增范围为 1–10000 次或 0.1–1000 km。按公里首次下单至少覆盖一次任务距离；结算使用执行前锁定的目标米数，不按额外轨迹误差追加扣费。
- 调整入口保持原计费方式，账号和计划受后端绑定约束；删除任务也不能抹掉预扣和结算历史。旧追加接口仅在原方式可用与在途额度耗尽后允许切换计费方式，历史结算仍保留于账本。
- 已购完整计划套餐优先使用，不重复购买按次 / 公里额度；完整计划套餐为固定权益，不属于此次次数 / 公里总量增减入口。

每条链接锁定生成时的账号、计划、区域、所属用户及单次距离、日/周频次和里程上限。范围内可调低或恢复参数，不可扩大上限。日范围也不得从工作日/周末扩大为每天。总预付额度在执行前校验；按公里链接的可选单次距离同时受当前剩余里程限制。额度正在被执行预留时，不能再次使用该部分额度。

每次读取、保存、照片上传都会重新校验当前套餐/预付额度及用户状态；额度用完、用户停用、套餐撤销或绑定变化后，链接暂停使用。预付方式或套餐类型变化后须重新生成链接。

若需扩大配置范围，由下单者在登录后调整任务，再轮换链接。此过程不会自动购买套餐或扣除余额。

### 链接保管

链接使用独立的随机令牌，不使用目标账号的登录 token。令牌放在 URL 的 `#token=` 片段中，调用 API 时通过 Authorization 请求头传递，不进入查询参数或 Referer。链接默认有效 30 天，可设为 1–365 天，支持轮换与撤销。

**不要泄露链接：持有者可以直接修改对应配置。** 已分享的旧人脸上传链接不再保留跨任务修改能力，升级后须从任务列表重新生成配置链接。账号正在执行任务时，请结束后再修改照片。

## 升级

新增手绘路线来源信息、任务下单与调整记录，以及可用 / 在途 / 已结算金额和版本字段。已有按次 / 公里预付按历史购买本金重分类，不重复扣余额，不返还历史已成功结算金额；迁移可重复执行，逐微保留舍入余数。升级前旧余额预扣中的任务仍能按原规则完成结算或失败返还。

已有任务默认保持自动路线；迁移不删除账号、任务、记录或计费数据，也不变更收款钱包、主密钥或充值方式。升级前备份数据库，在任务空闲时重启服务生效；一旦产生新版账务，不使用不理解预扣资金池的旧程序直接写入同一数据库。
