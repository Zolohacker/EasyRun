## 自动化回归

- `go test ./...`、`go vet ./...`、前端 TypeScript 检查与生产构建。
- 独立 PostgreSQL schema 下开启 `-race`：钱包配置分区隔离、私有 RPC URL / Key 加密与不回显、切换端点清理旧密钥。
- 模拟双服务验证：RPC 和索引各自使用自己的认证，不串发密钥；充值索引与固化回执不误发至第三方 RPC。
- 只读检测只访问预期的三个查询接口；普通客户、未登录请求被拒绝，超管检测限流生效。
- HTTP 200 的错误区块 / 缺失交易数组不视为检测通过。
- 无效交易回执、非固化回执、交易 ID 不匹配、错误代币合约、错误收款地址和失败状态不入账。
- 重复索引记录、重复扫描不重入账；同一交易的两个有效 Transfer 事件按事件索引各入账一次。
